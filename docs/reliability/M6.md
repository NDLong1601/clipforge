# M6 — Nghiệm thu fault, UI và gói phát hành

Ngày cập nhật: 03/10/2026 (Asia/Saigon).

Nghiệm thu bổ sung 04/10/2026 ở [R6](R6.md) và [R6_BASELINE.json](R6_BASELINE.json); các phép đo/giới hạn cũ dưới đây là lịch sử. R5 đã đóng F8: dependency psutil được khóa, telemetry thiếu chặn admission, volume data/temp có reservation và hysteresis, kiểm tra định kỳ trong encode, progress/ETA từng bước và event diagnostics có rotation. R6 kiểm native fault trước/sau sáu ranh giới bền với restart/API, race có barrier, benchmark API dưới encode thật và ZIP trong venv mới. Whole-job leases/pause riêng job, GPU telemetry, VM sạch, volume đầy thật và provider thật vẫn hoãn có chủ đích.

## Kết quả triển khai

- Thêm fault tests với monkeypatch ở test-only; không thêm endpoint fault injection vào ứng dụng.
- Kiểm tra render dừng ở final mux: clip/encode checkpoint hợp lệ được dùng lại, MP4 dở không được công bố, MP4 hoàn chỉnh phải qua kiểm tra hình/âm.
- Kiểm tra project commit đã ghi token nhưng chưa có receipt: startup tạo receipt phục hồi, không gọi callback/lưu project lần hai.
- Kiểm tra provider đang ở trạng thái `sending` sau restart thành `outcome_unknown`/`blocked`; gửi lại thiếu `confirm_cost` bị từ chối.
- Kiểm tra resume lặp không tăng attempt hai lần; state version cũ bị từ chối khi job đã thay đổi.
- Kiểm tra lỗi `ENOSPC` thành `DISK_FULL` và thu hồi resource lease; API queue giữ đủ 105 job hoạt động và không trả payload.
- Dọn cache bị chặn khi job lỗi/gián đoạn còn pin checkpoint; sau khi hủy job thì cache có thể được dọn.
- Gói source bỏ yêu cầu đối với `IMPLEMENTATION_PLAN.md` đã bị xóa khỏi workspace, đồng thời chứa tài liệu `docs/reliability` và manifest SHA-256.
- Trên Windows, chọn `aac_mf` nếu FFmpeg có encoder Media Foundation, còn máy khác dùng fallback `aac`. Validator giữ clock 48 kHz và kiểm tra số packet theo encoder; bài export 22 giây hoàn tất trong 5.20 giây trên máy này.
- Proxy VFR giữ timestamp passthrough và clone frame cuối khi track hình ngắn hơn thời lượng container do audio; proxy tiếp tục phủ đủ thời lượng asset.

## Chính sách checkpoint và retention

- Job có trạng thái `interrupted`, `error` hoặc `blocked` cùng `resume_capability=checkpointed` đang giữ dữ liệu cần để tiếp tục. Không dọn cache hoặc chuyển dự án chứa checkpoint vào thùng rác trước khi tiếp tục hoặc hủy job.
- Resume xác thực fingerprint và từng artifact trước khi dùng. Artifact mất/hỏng không được dùng; bước liên quan phải dựng lại hoặc UI báo tạo job mới nếu snapshot/cấu hình không còn khớp.
- Hủy job interrupted/error/blocked xóa manifest/checkpoint thuộc job và giải phóng pin. Dọn cache chỉ xóa cache có thể tái tạo sau khi không còn job pin; export của dự án vẫn được giữ.
- Khi render thành công, file tạm trung gian được xóa; final MP4 và project metadata cho export được giữ. Provider result payload được xóa khi job kết thúc; metadata job/lịch sử không có thời hạn tự xóa trong M6.
- Staging upload lỗi/gián đoạn có thể được giữ để tiếp tục; staging không còn được job nào giữ sẽ bị dọn khi khởi động. Không xóa thủ công `data/job_runs`/`data/staging` nếu cần phục hồi job.

## Kiểm tra tự động

Các test mới nằm tại `tests/test_reliability_m6.py`. Chạy từ PowerShell:

```powershell
.venv\Scripts\python.exe -m pytest tests/test_reliability_m6.py tests/test_m6_acceptance.py -q
npm --prefix frontend test
npm --prefix frontend run lint
npm --prefix frontend run build
```

Benchmark lặp lại baseline workload 60 giây, cold/warm preview, một fault tại mux và resume từ checkpoint, rồi đo p95 `/api/health` và `/api/jobs/queue` với 110 job chờ. Output JSON phải nằm ngoài repository:

```powershell
.venv\Scripts\python.exe tests/benchmark_m6.py --output "$env:TEMP\clipforge-m6-benchmark.json"
```

Lần chạy workstation ngày 03/10/2026 (Windows, Python 3.13.7, Node 24.14.0, FFmpeg imageio build `N-125875-g5d4d3bdc61-20260731`, AAC `aac_mf`) đo: tạo nguồn 0.49 s; phân tích 1.41 s/20 cảnh; cold render 11.12 s bằng `h264_qsv`; warm render 5.24 s với 1 clip hit; lần chạy bị ngắt tại mux 4.23 s; resume 1.62 s với 1 clip hit/0 miss. Health p95 là 65.89 ms, queue p95 là 34.53 ms với 110 job chờ, đạt mục tiêu ban đầu dưới 500 ms. Peak process-tree working set: cold render 302.0 MB, warm 311.8 MB, resume 99.7 MB. Output MP4 598,758 bytes.

Nghiệm thu cuối: backend `157 passed` trong 325.87 s; frontend `24 passed`; Biome lint và Vite production build thành công; test manifest ZIP `1 passed`. Có một cảnh báo deprecation từ `starlette.testclient`/`httpx`, không làm fail test.

M0 ghi cold 10.71 s/warm 4.39 s với FFmpeg 7.1; M6 dùng imageio FFmpeg build khác và máy/phiên chạy cùng workstation nên đây chỉ là số đo tham khảo, không kết luận hiệu năng giảm/tăng giữa hai mốc. Báo cáo chi tiết ở `%TEMP%\clipforge-m6-benchmark.json`; output không chứa Git root hay project path. Số đo là một lần trên một workstation, không phải cam kết cho máy khác.

## Windows, cài mới, nâng cấp và rollback

- Gói ZIP được giải nén vào `ClipForge M6 sạch 2026-10-03` dưới `%TEMP%` (tên thư mục chứa dấu và khoảng trắng). `launch.py --setup-only` tạo virtualenv Python 3.13.7 mới và cài thành công `requirements-lock.txt`. Đây xác nhận setup sạch ở mức user-space; không tương đương cài Windows mới/clean VM.
- Chạy server từ bản ZIP ở port 18765. Browser smoke mở trang Tác vụ và thấy `Đã đồng bộ`; dừng backend làm UI hiện `Mất kết nối · đang giữ trạng thái gần nhất`; khởi động lại server làm UI trở về `Đã đồng bộ`. Các lỗi console khi server tắt chỉ là request polling bị `ERR_CONNECTION_REFUSED`; không có JavaScript error hay warning.
- Test migration schema v4 → v7 kiểm tra idempotence và giữ nguyên ID. Trước khi migration lần đầu, ứng dụng tạo bản sao schema cũ; kiểm tra/khôi phục qua **Dung lượng → Backup** trước khi mở dữ liệu bằng runtime cũ.
- Để quay lại: dừng ClipForge, giữ nguyên thư mục data, chạy bản mã/build trước đó trên bản sao dữ liệu hoặc phục hồi backup trước migration. Không mở trực tiếp schema v5 bằng backend cũ và không xóa `job_runs` của runtime mới bằng phiên bản cũ.
- Không chạy API provider thật nếu không có khóa/ủy quyền riêng. Kịch bản fault/provider trong suite đều mô phỏng, không phát request tính phí.

## Giới hạn nghiệm thu

- `tests/test_reliability_m6.py` đo resume sau lỗi ngay trước lệnh mux; crash thật ở mọi điểm FFmpeg, ghép source audio, H.265 và nhiều clip được kiểm bằng subprocess/fixture riêng, không phải mọi trường hợp trong bảng kế hoạch.
- Browser smoke kiểm tra trang Tác vụ, queue và phát hiện backend offline/reconnect trên ZIP sạch. Không thay thế test đa-tab/race trên máy nhiều người.
- Không nghiệm thu Windows VM sạch, hardware encoder khác, thiếu RAM/volume thử nghiệm, dịch vụ AI thật hoặc voice tiếng Việt tự nhiên trên máy này.
- Nếu thiếu môi trường ngoài workstation hiện tại, bản build được gọi là ứng viên phát hành đã qua suite cục bộ; chưa gọi là release đã chứng nhận đa môi trường.
